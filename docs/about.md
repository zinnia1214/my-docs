# 关于本项目

## 项目目标

实现从 Markdown 文档到公开网站的自动化发布，并通过本站整理 Git 与 GitHub 的基础知识。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容 |
| MkDocs Material | 将文档构建成静态网站 |
| GitHub Actions | 自动执行安装、构建和部署 |
| GitHub Pages | 托管并提供网站访问地址 |

## 为什么选择这个主题

在课程中我已经使用过 Git 和 GitHub，但很多概念（如提交、分支、远程仓库）还不够清楚。通过把它们整理成笔记网站，可以帮助自己巩固理解。

## 我的实践体会

> 这次亲手把仓库克隆到本地、配置 Git 身份信息的过程，让我搞懂了 Git 和 GitHub 不是同一个东西。之前只模糊知道可以上传代码，实操时才明白 `clone`、切换目录、配置用户名邮箱这些步骤各自的作用。中途跟着教程一步步操作，也体会到命令输入不能出错，路径选错就会找不到仓库。这个项目让我学会把 Markdown 笔记交给 Git 管理，后续也会慢慢熟悉提交、推送、更新的完整流程，把零散的知识点整理成可以在线访问的文档网站。
