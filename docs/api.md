# API 参考

本页分为两部分：第一部分是按作业要求编写的 **文档示例**（仅用于练习 API 描述，不提供真实服务）；第二部分是 **常用 Git 命令参考**。

## 文档示例：查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## Git 命令参考

| 命令 | 作用 |
| --- | --- |
| `git status` | 查看当前文件的修改状态 |
| `git add <文件>` | 把修改加入暂存区 |
| `git commit -m "说明"` | 保存一次版本记录 |
| `git push origin main` | 推送到 GitHub 的 main 分支 |
| `git log --oneline` | 查看提交历史 |

更多流程说明请见 [日常使用指南](guide.md)。
